# Paper

A small, English personal notebook Theme for [escaping](https://github.com/geoqiao/escaping),
part of the [escaping-themes](https://github.com/geoqiao/escaping-themes) repository.
Paper uses warm paper colours, serif text, a narrow reading column and system
fonts. It is independent of Quiet and has no build tools or bundled
JavaScript. MIT licensed; see [LICENSE](LICENSE).

Its entire rendering layer is `blog.html`, `post.html`, one shared `base.html`
and `static/paper.css`, plus the `api: 4` manifest. The light appearance stays
light even when the reader prefers dark mode.

## Pages and required settings

| Page | How Paper renders it |
| --- | --- |
| Home | `blog.html`: profile introduction, first page of recent posts, link to Blog |
| Blog, including page 2 and beyond | `blog.html`: dated titles, summaries, tags, newer/older pagination |
| Post | `post.html`: title, date, tags, full body and neighbouring posts |
| Ideas list | `blog.html`: all Ideas, newest first, with their own heading |
| Individual Idea | `post.html`: title, date, full body and neighbouring Ideas |
| About from an Issue | `post.html`: title and body, without a date |
| About from the profile | `post.html`: author and bio, without a date or comments |
| Tags index / tag archives | Unsupported; turn tags pages off |
| Projects | Unsupported; turn the Projects page off |
| 404 | No custom template; your hosting service supplies its normal missing-page response |

Merge this into your site's existing `config.yaml` (do not duplicate YAML keys):

```yaml
site:
  language: en
  navigation:
    items:
      - {name: Home, url: /}
      - {name: Blog, url: /blog/}
      - {name: Ideas, url: /ideas/}
      - {name: About, url: /about/}
      - {name: RSS, url: /atom.xml}
theme:
  use: github.com/geoqiao/escaping-themes/paper@v1.0.0
pages:
  tags: false
  projects: false
  ideas: true
  about: true
paths:
  page_size: 2
```

`tags: false` and `projects: false` are required. Ideas and About default to on;
they can also be disabled if you remove their explicit menu entries. An explicit
menu replaces the whole default menu. Ideas is absent from escaping's default
menu, which is why this example includes it. If you move a section with
`pages.blog`, `pages.ideas` or `pages.about`, update its explicit menu URL too.
Paper takes its own links from routes, so root sites and sites under a path
such as `https://alice.example/notes/` work without editing templates.

Page size is a site setting, not a Theme option. Four posts at size 2 produce
two Blog pages. Home shows the first two; Ideas is not paginated. Empty lists
show a short empty-state message.

### What happens with tags enabled?

Tag pages are on by default in escaping. Selecting Paper without disabling
them makes both `escpe theme check` and `escpe build` exit **1**. For example,
with the Theme installed at `themes/paper`, the build prints:

```text
error: paper: has no tags.html for the tags page /tags/; add tags.html to the Theme, or set pages.tags: false in config.yaml
Build failed; the previous output was left unchanged.
```

The check ends with `Theme check failed.` instead of the build's last line.
The Theme name and page address may differ with your folder and page settings.
The missing tags index has no fallback; a list template alone does not enable
tag support. Keep `pages.tags: false` for this release. A fork adding tags
would need `tags.html` plus a tag-aware archive template or branch. With tags
off, post and Idea tags still appear as plain text, never broken links.
Leaving Projects on similarly fails and names `projects.html` and
`pages.projects: false`.

## Options, content and extra pages

Paper declares **no Theme options**. Omit `theme.options` or use `{}`; remove
any options left over from Quiet. Edit the CSS variables in `static/paper.css`
for local colour changes. Site title, author, description, profile bio, profile
links and navigation come from the usual site fields. UI labels are English.

**No extra-page templates are shipped.** There are no `pages.extra` entries to
add; leave it absent or set `pages.extra: []`. `base.html` is a layout, not a
standalone page template.

Code blocks and tables are styled. Mermaid uses escaping's bundled loader and
runtime, so diagrams need no external service. RSS/Atom, sitemap and search
JSON are generated by escaping; Paper has an RSS link but no search interface.
It emits titles, descriptions, canonical URLs, basic Open Graph metadata and
the generator's JSON-LD. It does not implement social preview images or a
Google verification meta tag.

Descriptions are the generator's plain-text summaries. For a post dominated
by a table or code, add `description` in the Issue's front matter for a more
readable summary; Paper does not rewrite Issue content.

Comments are off by default. Paper honours `comments.enabled: true` and
`comments.repo`, using escaping's shared Utterances script with a fixed light
theme on Issue-backed posts, Ideas and About. You must separately install the
Utterances GitHub App. If the widget fails to load, the shared script supplies
a source-Issue link. Profile About never has comments. Live comment submission
was not tested; offline fallback and Issue-number binding were tested.

## Use it

With escaping 0.4.0 or later, point `theme.use` at the GitHub address shown in
the config example above; escaping downloads the Theme. To update, change the
version after `@`. To customize a few files, make a site-owned folder with a
`theme.yaml` containing `api: 4` and
`extends: github.com/geoqiao/escaping-themes/paper@v1.0.0`, set
`theme: {use: ./theme}`, and add only the files you want to replace —
`@paper/` reaches the originals. See escaping's
[guide to using a Theme from GitHub](https://github.com/geoqiao/escaping/blob/main/docs/themes/authoring.md#using-a-theme-from-github).

With escaping 0.3.0, which does not download Themes, copy this folder into
your site as `themes/paper/` and set `theme: {use: ./themes/paper}`.

From the site directory, run:

```sh
escpe theme check --config config.yaml
escpe build --config config.yaml --issues-json issues.json
```
